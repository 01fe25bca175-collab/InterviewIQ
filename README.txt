INTERVIEWIQ — CODEFEST MVP
RUN:
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Safari.
3. Choose job role, experience, interview type and difficulty.
4. Start interview, answer/skip five questions, then show the report.

No installation, server, internet connection, or API key required.

FUNCTIONS:
- Role-specific interview questions
- Candidate configuration
- Question-by-question text interview
- Skip/end controls
- Heuristic scoring for detail, relevance, examples, structure and clarity
- Strengths, improvement suggestions, practice plan
- Downloadable report

IMPORTANT:
This fast prototype uses transparent rule-based feedback, not a live LLM. Be honest about this if asked. The report is a demo coaching score, not a validated assessment or hiring prediction.

DEMO RUN-THROUGH:
Select Frontend Developer / Student-Fresher / Technical / Intermediate.
Answer in full sentences and include words like React, component, example, because, first, result where relevant.
Finish and demonstrate the report and Download report button.
